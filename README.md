# Agri Supply Chain Management

> **⚠️ NOTE:** This project is currently **under active review and development**. Features and functionalities are subject to change.

## 🌾 Project Overview

This is a comprehensive **Agriculture Supply Chain Management System** designed to bring transparency, efficiency, and security to the agricultural value chain. By leveraging modern web technologies and blockchain integration, this platform aims to track produce from farm to table, ensuring quality and trust.

## 🚀 Key Features

- **Supply Chain Tracking:** Real-time tracking of agricultural products using blockchain technology for immutable records.
- **Secure Authentication:** Robust user management system with JWT and bcrypt for secure access.
- **Interactive Dashboards:** Visual analytics using Chart.js and Recharts to monitor supply chain performance.
- **QR Code Integration:** Generate and scan QR codes for easy product verification and tracking.
- **Digital Records:** Paperless management of transactions and product details.

## 🛠️ Tech Stack

This project is built using the MERN stack with blockchain capabilities:

### Frontend
- **Framework:** React (Vite)
- **Styling:** Tailwind CSS, Framer Motion
- **Blockchain:** Ethers.js
- **Visualization:** Recharts, Chart.js

### Backend
- **Runtime:** Node.js
- **Framework:** Express.js
- **Database:** MongoDB (Mongoose)
- **Authentication:** JWT, Bcrypt
- **Utilities:** Multer (File Uploads), QRCode

## 🚧 Status

This project is in the **Development Phase**. Code structure, API endpoints, and smart contract integrations are being optimized.
